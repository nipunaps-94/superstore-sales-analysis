# Superstore Sales Analysis Dashboard

## Project Overview
This project analyzes Superstore sales and profitability data using Excel dashboards and business intelligence techniques.

## Objectives
- Analyze sales trends
- Identify profitable categories and regions
- Track business performance
- Generate actionable business insights

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers
- KPI Reporting

## Dashboard Features
- Total Sales Analysis
- Profitability Tracking
- Monthly Sales Trends
- Regional Performance
- Category-Level Insights
- Interactive Filters

## Key Insights
- The technology category generated the highest sales revenue.
- The central region showed the strongest profitability.
- Q4 sales demonstrated significant growth trends.
- Certain products showed low profit margins despite high sales.

## Outcome
This project demonstrates beginner-level data analytics skills, including data cleaning, visualization, dashboard creation, and business insight generation.
